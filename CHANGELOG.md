# Changelog

## 0.4.0 — 2026-10-17 (Unspill public alpha)

- Unspill branding across the command, Python package, documentation, and downloads.
- Independent configuration through UNSPILL_HOME and Unspill default store paths.
- No former command alias, environment fallback, or automatic old-store discovery.
- A dated preliminary naming-screening record with sources and limitations.
- Apache-2.0 licensing and Robert Al-Malak's authorship retained.

## 0.3.0 — 2026-10-16 (public alpha)

- Descriptive checkpoints with branch, commit subject, changed paths, stash names,
  and separately recorded command outcomes.
- Stable numbered selectors, timeline search, file history and text comparisons.
- Guided terminal recovery and previews against the current workspace.
- Native Windows support and Windows/macOS/Linux Python 3.11–3.14 CI.
- Standalone executable builds for four platform/architecture targets.
- Installation, command, storage and testing guides.
- 115 tests and an opt-in real public repository recovery demonstration.

## 0.1.0 — 2026-10-16 (public alpha)

- Permanent, append-only snapshots outside protected repositories.
- Compressed and deduplicated contents, including independent Git metadata.
- Checkpoints before supported Git commands; failed checkpoints block execution.
- Timeline, inspection, reversible restore, selective export and verification.
- A recovery journal for interrupted restoration.
- Apache-2.0, contributor guide, architecture notes and recovery demo.
- 80 storage, real-Git integration and CLI tests.
